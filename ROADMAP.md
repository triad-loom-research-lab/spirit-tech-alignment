# Spirit-Tech Alignment Roadmap

Spirit-Tech Alignment is currently in the **pre-v0.1 research framework stage**.

The project is being developed openly so that its assumptions, architecture, moral primitives, and technical mechanisms can be challenged before they are treated as established.

## Current Foundation

The project currently includes:

- research framework and architecture
- documented research lineage
- working preprint
- candidate moral primitives
- formal research hypotheses
- proposed evaluation metrics
- adversarial testing strategy
- falsification criteria
- related-work positioning

## Pre-v0.1 Priorities

### 1. Formalize Candidate Moral Primitives

Develop explicit working specifications for:

- Truth
- Dignity
- Justice
- Mercy
- Stewardship
- Faithfulness
- Accountability
- Restraint

Each primitive should include:

- working definition
- assumptions
- operational interpretation
- potential violations
- edge cases
- conflicts with other principles
- uncertainty
- possible tests

### 2. Define the First Benchmark

Create a small initial benchmark focused on situations where:

- task success conflicts with a moral constraint
- authority conflicts with legitimacy
- incentives encourage deception or concealment
- principles conflict with one another
- safe action may require HALT or ESCALATE

### 3. Build a Minimal Reference Implementation

Develop the smallest practical implementation of:

**candidate principle  
→ HSI analysis  
→ Triad Loom verification  
→ DecisionGate execution decision**

The first objective is not a production system.

The objective is to determine whether the architecture can be tested.

### 4. Invite External Critique

Seek review from researchers and practitioners in:

- AI safety
- software engineering
- formal methods
- cybersecurity
- machine ethics
- philosophy
- theology
- human-centered AI
- governance

Critical feedback, counterexamples, and falsification attempts are encouraged.

### 5. Prepare v0.1

Before the first versioned release:

- refine the preprint
- verify references
- finalize licensing
- create citation metadata
- establish contribution guidelines
- publish an initial benchmark specification
- document the first reproducible experiment

## Research Principle

The goal is not to prove Spirit-Tech Alignment correct.

The goal is to determine which parts survive explicit definition, adversarial testing, implementation, criticism, and replication.
